# Jagad Stockis

**Franchise Supply, Stock & Order Management Platform**

Jagad Stockis is a full-stack platform for managing franchise supply operations, product availability, stock, orders, and administrative workflows. It combines a customer-facing ordering experience with an internal control center for operational management.

## Highlights

- Product catalog and stock availability
- Shopping cart and order workflow
- Administrative dashboard
- Product and inventory management
- Order management
- Partner / franchise account management
- Secure admin access
- Responsive desktop and mobile experience

## Engineering Focus

This project demonstrates end-to-end application development across storefront UX, admin workflows, database integration, stock management, authentication, and production deployment.

## Tech Stack

- **Framework:** Next.js 16, React 19, TypeScript
- **Database / ORM:** Prisma 6
- **UI:** Tailwind CSS, Radix UI, Lucide React
- **State & Validation:** Zustand, Zod, React Hook Form
- **Authentication:** NextAuth
- **Tables & Data:** TanStack Table, React Query
- **Visualization:** Recharts
- **Motion / UX:** Framer Motion

## Core Modules

### Storefront
Browse available products, view stock information, choose quantities, and build orders through a responsive interface.

### Inventory Management
Track product availability and maintain stock information from the administrative control center.

### Order Operations
Manage incoming orders and operational activity from a centralized admin dashboard.

### Partner Management
Support franchise or partner account workflows as part of the supply network.

## Product Direction

Jagad Stockis is designed as a scalable digital operations platform for franchise supply networks, connecting ordering, inventory, and administration in one system.
